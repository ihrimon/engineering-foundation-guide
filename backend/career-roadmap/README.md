# Career in Backend — A Life Long Roadmap

*By **HM Nayem** — Author & Educator, Founder & CTO at Stack Learner, Technical Screener & Full-stack Developer at Toptal*

⬅ [Back to Backend Guide](../README.md) · [Main guide](../../README.md)

A 3-day narrative walkthrough of what backend engineering actually is, why it gets hard once real users show up, and the two realistic paths (common vs. career) to grow into a backend architect.

## Contents

| Day | Title | Summary |
|---|---|---|
| 1 | [Big Picture of Backend](day-1.md) | What backend *is* — from flat files to databases to the web server / application / database / server model. |
| 2 | [Problem with Backend](day-2.md) | Why a single server stops being enough, and the three interrelated phases — Development, Deployment, Distribution — that solve it. |
| 3 | [Journey to Become an Architect](day-3.md) | The Common Path vs. the Career Path, backend job roles, the CS/System Design foundation to build, and interview preparation. |

## How to use this roadmap

1. Read the days in order — each one builds on the last.
2. Once you've finished Day 3, use the **[Backend Guide](../README.md)** checklist to turn the concepts into a hands-on study plan, topic by topic.
3. Pair it with the **[Frontend Guide](../../frontend/README.md)** and **[DevOps / Infrastructure Guide](../../devops/README.md)** for the full-stack picture.
